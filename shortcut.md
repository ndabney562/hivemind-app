# HiveMind Phone Shortcut

When the Mac doesn't answer, the HiveMind app on the iPhone asks the person's own AIs through one Shortcut named
**HiveMind Phone**. The app opens it with `shortcuts://run-shortcut?name=HiveMind%20Phone&input=text&text=…`; the
Shortcut copies its result to the clipboard, and you switch back to HiveMind and paste it into the box the app shows.
(A return link would reopen in Safari, not in the Home Screen app, so the answer comes back by paste: tested on an
iPhone 16 Pro, iOS 26, 2026-11-01.)

**Install it (one tap):** on the Mac run `hivemind phone shortcut` and click **Add Shortcut** (iCloud copies it to the
iPhone), or open `HiveMind Phone.shortcut` from the friend site on the iPhone. It is generated by
`hivemindcore/phone_shortcut.py` and signed for anyone. It only uses apps the person is already signed in to. The steps
below say what it does, and are how to build it by hand if the file won't install.

## Contract

- **Input** (Shortcut Input, text): JSON `{"prompt": "...", "order": ["claude-app", "apple-cloud", ...]}`.
  `prompt` is the full question (About you and recent turns already added by the app). `order` lists the AIs to try,
  best first, and only ones the person ticked under Settings › Your AIs.
- **Output** (Copy to Clipboard, then Stop and Output; a Dictionary becomes JSON text):
  `{"model": "<id>", "ok": true|false, "answer": "<text>"}`. `model` is the id that answered (or the last one tried).

## AI ids and the action each one uses

| id | action |
|---|---|
| `apple-local` | Apple Intelligence **Use Model**, model **On-Device** |
| `apple-cloud` | Apple Intelligence **Use Model**, model **Cloud** (Private Cloud Compute) |
| `claude-app` | Claude app **Ask Claude** (needs the Claude app, signed in) |
| `chatgpt-app` | ChatGPT app **Ask ChatGPT** (needs the ChatGPT app, signed in) |

## Steps

1. New Shortcut, name it exactly `HiveMind Phone`. In its details, leave **Show in Share Sheet** off; it receives **Text**.
2. **Get Dictionary from** Shortcut Input.
3. **Get Dictionary Value** for key `prompt` → **Set Variable** `Prompt`.
4. **Text** `(none)` → **Set Variable** `Answer` (iOS 26 has no "has any value" check for text, so `(none)` marks "not answered yet").
5. **Get Dictionary Value** for key `order` → **Repeat with Each** item:
   1. **Text** `Answer`, then **If** Text **is** `(none)` (Shortcuts has no "break", so this check is how it can stop at the first answer):
      1. **Set Variable** `Model` to Repeat Item, then **Text** Repeat Item (so the Ifs below compare text).
      2. **If** Text **is** `apple-local` → **Use Model** (On-Device) with `Prompt` → **Set Variable** `Answer`.
      3. **If** Text **is** `apple-cloud` → **Use Model** (Cloud) with `Prompt` → **Set Variable** `Answer`.
      4. **If** Text **is** `claude-app` → **Ask Claude** with `Prompt` → **Set Variable** `Answer`.
      5. **If** Text **is** `chatgpt-app` → **Ask ChatGPT** with `Prompt` → **Set Variable** `Answer`.
   2. End If.
6. After the loop: **Text** `Answer`, then **If** Text **is** `(none)` → **Dictionary** `model` = `Model`, `ok` = false
   (Boolean), `answer` = `No AI on this phone answered`. **Otherwise** → **Dictionary** `model` = `Model`, `ok` = true,
   `answer` = `Answer`.
7. **Text** of the If Result (the Dictionary as JSON; a Dictionary itself pastes as nothing).
8. **Copy to Clipboard** that Text.
9. **Stop and Output** that Text.

Leave out a branch for an app the phone doesn't have, and untick it under Your AIs. The model is picked by tapping the
blue word right after "Use" in the Use Model action (the menu lists Cloud, Cloud Pro, On-Device and ChatGPT).

**When an AI fails.** An empty answer ends the loop too, and HiveMind shows it as failed. An action that *errors* (app
signed out, no network) stops the whole Shortcut, so there is nothing to paste: tap **Cancel** in HiveMind, then resend
or pick another AI in Options. Sign in to the app to fix it.

## Check it

On the iPhone, open HiveMind with the Mac off (or Tailscale off), tick your AIs under Settings › Your AIs, and ask
"define osmosis". Shortcuts opens and answers. Switch back to HiveMind (swipe along the bottom edge), tap the box, choose **Paste**: the
answer shows tagged "phone only, not checked".
